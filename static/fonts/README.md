# 汇文明朝体

原作者：特里王。字体声明：Public Domain。本站使用汇文明朝体符号修正版。

来源：https://github.com/bosswnx/huiwenmincho-improved
固定版本：40b9dbb9bfa51bc4979b62d0dcd3bc064c5ea049
授权原文见 Huiwen-Mincho-LICENSE.txt。

首次本地构建请运行 `python3 -m pip install fonttools==4.61.1`。
`npm run build` 自动校验源字库并生成覆盖当前页面与文章文字的 WOFF 字体。
新增文章后重建会自动补入新增字符，生成文件与网站一起部署，不依赖访客访问外部字体服务。
